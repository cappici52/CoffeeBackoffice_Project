# ตรวจความพร้อมร้านและพยากรณ์ ข้อ 7–12

ตรวจฐานร้านและคำนวณคะแนนซ้ำวันที่ 5 พฤศจิกายน 2569 ใช้คำสั่ง `npm run ops:check` เพื่อตรวจข้อมูลร้านอีกครั้ง คำสั่งนี้อ่านข้อมูลอย่างเดียว

## 7–9 เมนู สต็อก และจัดซื้อ

| รายการ | ผลตรวจและสิ่งที่ต้องยืนยัน |
|---|---|
| เมนูและสูตร | เมนูเปิดขาย 8 รายการ มีรูปและสูตรครบ วัตถุดิบใช้หน่วยฐาน g, ml หรือชิ้น ตรวจตัวเลือกที่เพิ่มหรือแทนวัตถุดิบกับสูตรแล้ว ตัวเลือกไม่หวานที่แทนน้ำเชื่อมด้วยปริมาณศูนย์เป็นค่าที่รองรับ |
| ต้นทุนและสต็อก | วัตถุดิบ 10 รายการมีต้นทุนมาตรฐานต่อหน่วยในระบบและยังรอตรวจนับ ต้นทุนมาตรฐานใช้ประกอบการคิดต้นทุนสูตร ล็อตเก่าทั้ง 10 ล็อตยังไม่ทราบราคาซื้อจริงและวันหมดอายุ นมโอ๊ตอยู่ต่ำกว่าจุดสั่งเพิ่มตามยอดบัญชี |
| ซัพพลายเออร์ | ยังไม่มีซัพพลายเออร์ที่เปิดใช้งานและใบสั่งซื้อค้างรับ เจ้าของร้านเพิ่มผู้ขายและเวลาส่งจริงในแท็บจัดซื้อได้ เมื่อรับสินค้าให้ระบุจำนวนและราคาต่อหน่วยฐาน พร้อมวันหมดอายุหรือสถานะของล็อต |
| แผนสั่งเพิ่ม | ใช้รอบพยากรณ์ร้านที่ไม่มีข้อมูลจำลอง คิดเฉพาะเมนูที่ยังเปิดขาย ตรวจสูตรและสถานะตรวจนับจากบัญชีสต็อก คำนวณตามล็อตและวันคาดรับ แยกปริมาณขาดก่อนของมาถึงจากปริมาณเติมถึงรอบทบทวน |

แผนระบุวันคาดรับและวันสิ้นสุดรอบทบทวน เมื่อไม่มีค่าพยากรณ์วันนี้จะเริ่มพิจารณาความต้องการตั้งแต่พรุ่งนี้และแสดงขอบเขตนี้บนหน้าจอ ระบบเว้นวันที่เสี่ยงขาดและปริมาณสั่งเพิ่มเมื่อเมนูหรือช่วงเวลาครอบคลุมไม่ครบ ล็อตไม่ทราบวันหมดอายุ ใบสั่งซื้อเลยกำหนด หรือสต็อกยังรอตรวจนับจะขึ้นให้ตรวจอีกครั้ง ตัวเลือกเมนูและของเสียยังอยู่นอกการคำนวณจากสูตรพื้นฐาน

## 12 แยกแหล่งข้อมูล

- **ร้าน** ตรวจพบออเดอร์ไม่ติดป้ายจำลอง 10 รายการ ส่งมอบแล้ว 8 รายการใน 2 วัน ยังไม่มีวันขายที่ปิดยอดหรือรอบที่ฝึกจากชุดร้านตามเกณฑ์ จึงยังไม่มีคะแนนล่วงหน้า 1/7/30 วันที่ใช้ตัดสินความแม่นยำของร้าน รายการไม่ติดป้ายจำลองยังไม่ยืนยันที่มาว่าเป็นลูกค้าจริง
- **จำลอง** ออเดอร์ที่ติดป้ายจำลองในร้านมี 0 รายการ ประวัติรอบพยากรณ์จำลองยังเก็บเป็นหลักฐาน แผนสั่งเพิ่มไม่รับรอบจำลองหรือรอบเก่าที่ระบุชุดฝึกไม่ชัด และการฝึกไม่อนุมานยอดศูนย์ให้เมนูที่ไม่ขายในวันที่หลักฐานปิดวันขัดกับแหล่งของออเดอร์
- **สาธารณะ** เก็บในตารางวิจัยและใช้ใน Historical Replay การตรวจคะแนนซ้ำอ่านไฟล์วิจัยโดยไม่เขียนยอดร้าน สต็อก หรือพยากรณ์ที่บันทึกไว้
