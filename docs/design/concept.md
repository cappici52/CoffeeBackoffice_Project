# POS visual reference

Generated with the built-in ImageGen tool (ui-mockup). Saved reference: `docs/design/pos-concept.png`.

Final generation brief: a complete Thai Coffee Backoffice desktop POS, dark minimal matte charcoal #171A1C / #212628, light text #EDF0ED, muted #B1BDB9, restrained sage #A7C4B5; narrow left navigation for POS, orders, KDS, menus, stock/recipes, reports, forecasts and users; top page title/date/connection; center search, category tabs and text-only product tiles; right order panel with dine-in/takeaway, item options and quantities, note, total, cash/PromptPay and confirm-payment action. Thin dividers, 8px corners, readable Noto Sans Thai-like typography and tabular order numbers. No marketing hero, gradients, photography, decorative metrics or device frame. All controls and text implemented natively in React/CSS.

The live application uses real dates, seeded menu names/categories and transactional totals; the concept's sample dates/items are illustrative. Extra operational states (unpaid order, connection failure, permission errors, version conflicts) extend the same system. Desktop reference comparison and narrow-screen browser tests informed the final layout.
