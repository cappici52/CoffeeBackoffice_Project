# ผลจำลองการขายผ่านร้านเดิมในฐานหลัก — 3 พฤศจิกายน 2026

ทำตามคำขอเจ้าของให้จำลอง workflow ย้อนหลังใน **แอปหลัก / ฐาน `coffee_backoffice`** โดยใช้ 8 เมนู ราคา ตัวเลือก สูตร วัตถุดิบ และโต๊ะ QR เดิม ไม่คัดลอกออเดอร์จากฐานจำลองก่อนหน้า และไม่สร้าง catalog ร้านใหม่

รายการขายที่เพิ่มเป็น **ข้อมูลจำลอง** ไม่ใช่ลูกค้าหรือเงินรับจริง รายงานและ stock ของฐานหลักรวมรายการเหล่านี้แล้ว แอปแจ้งที่มาในทุกหน้าหลังเข้าสู่ระบบ และแยกคะแนนพยากรณ์จำลองออกจาก genuine-sales accuracy
