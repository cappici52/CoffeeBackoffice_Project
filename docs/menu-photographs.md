# ภาพถ่ายเมนู

## เพิ่มรูปจากเครื่อง

เจ้าของร้าน/ผู้จัดการเปิด **เมนู → แก้ไข → เลือกรูปจากเครื่อง** เลือก JPG/PNG/WebP ดูตัวอย่าง แล้วกด **บันทึกเมนู** รูปจะแสดงใน POS และหน้าลูกค้าผ่าน QR ยกเลิกรูปที่เลือกก่อนบันทึกได้ และยังใช้ลิงก์ HTTPS ของรูปโดยตรงได้ ไม่มีเครดิต/ลิงก์แหล่งภาพแสดงในแอป ใช้รูปที่ตนเป็นเจ้าของหรือได้รับอนุญาตให้เผยแพร่

รับไฟล์ไม่เกิน 5 MiB/25 ล้านพิกเซล ตรวจข้อมูลรูปจริงก่อนแปลงเป็น WebP สูงสุด 1600 × 1600 โดยไม่ขยายภาพ ลบ metadata เดิมรวม EXIF/GPS และไม่แก้ไฟล์ต้นฉบับในเครื่อง ไม่รองรับ SVG/ภาพเคลื่อนไหว/ไฟล์เสีย อ้างอิง [Sharp constructor](https://sharp.pixelplumbing.com/api-constructor/) และ [output](https://sharp.pixelplumbing.com/api-output/) จำกัดอัปโหลด 30 ครั้งต่อบัญชีต่อชั่วโมงต่อ API process

เก็บไฟล์ในตาราง `menu_images` ของ PostgreSQL จึงสำรองไปพร้อมฐานข้อมูล URL สาธารณะใช้ SHA-256 ไม่ใช้ชื่อไฟล์จากเครื่อง การติดตั้งร้านเดียวเก็บรูปเก่า/รูปที่ยังไม่ผูกเมนูไว้เพื่อให้ลิงก์และ retry คงที่ ควรติดตามขนาดฐานข้อมูลและไม่อัปโหลดเอกสารส่วนตัว ถ้าอัปโหลดสำเร็จแต่บันทึกเมนูล้มเหลว รูปอาจยังไม่ผูกเมนู การลองซ้ำจะใช้ไฟล์เดิมตาม hash

ตามคำขอผู้ใช้: ใช้ภาพถ่ายจริงเท่านั้น และไม่แสดงลิงก์ต้นฉบับ/ชื่อสัญญาอนุญาต/เครดิตบนหน้าจอ

- ภาพประกอบ 8 เมนูอยู่ใน `client/public/menu/` ให้บริการจากเครื่องร้านผ่าน `/menu/*.jpg` ใช้งานบน LAN ได้ ไม่ hotlink รูปหรือส่งคำขอรูปไปยังบุคคลที่สามระหว่างเลือกเมนู
- เลือกเฉพาะภาพ **CC0 หรือ public domain** ที่ไม่บังคับแสดงเครดิต คงข้อมูลแหล่งที่มา ช่างภาพ วันที่ ใบอนุญาต และ SHA-256 ไว้ใน `docs/menu-photo-sources.json` เพื่ออ้างอิงภายในโปรเจกต์
- แหล่งภาพเป็น Wikimedia Commons ใช้หลักฐานหน้าไฟล์/ผู้ถ่าย/ประวัติภาพ/ข้อมูลกล้องประกอบการเลือก ไม่มีภาพจากงานสร้าง AI ถูกนำมาใช้หรือคัดลอกเข้าโปรเจกต์
- ภาพเป็นภาพประกอบประเภทเมนูจากภายนอก ไม่ใช่ภาพสินค้าที่ถ่ายจากร้านนี้ ภาพแต่ละเมนูอาจเป็นรูปแบบร้อน/เย็นหรือการตกแต่งที่ต่างจากสินค้าจริง เจ้าของร้านเปลี่ยนเป็นภาพของตนได้ในหน้าแก้ไขเมนูด้วย HTTPS URL
- ย่อขนาดโดยบริการ thumbnail ของ Wikimedia เท่านั้น ไม่มีการแต่งหรือสร้างส่วนของภาพด้วย AI หน้าเมนูใช้ CSS จัดกรอบภาพ; หน้าพรีวิวแสดงภาพเต็มในกรอบ
- Migration `008_menu_photographs.sql` เติมรูปเฉพาะเมนูชื่อที่รู้จักซึ่งยังไม่มีรูป พร้อมเพิ่ม version เพื่อป้องกันการบันทึกจากฟอร์มเก่าทับข้อมูล ไม่เปลี่ยนภาพที่เจ้าของใส่ไว้แล้วหรือเมนูที่เก็บออกจากการขาย
- ข้อมูลเริ่มต้นชุดใหม่มีรูปครบ 8 เมนูตั้งแต่ seed การเพิ่มเมนูชื่อใหม่ยังต้องระบุรูปของเมนูนั้นเอง หากไม่ระบุหรือโหลดไม่ได้จะเห็นพื้นที่สำรองแทนไอคอนรูปเสีย
- `MenuPhoto` ใช้ร่วมกันใน POS/QR, รายละเอียดตัวเลือก, รายการจัดการเมนู และพรีวิวตอนแก้ไข พื้นที่ภาพจองขนาดไว้เพื่อลด layout shift และไม่ทับชื่อ/ราคา/ปุ่มสั่ง

หากต้องดาวน์โหลดจากต้นทางใหม่ ใช้ `python scripts/sync-menu-photos.py` ซึ่งตรวจชนิด license ก่อนรับไฟล์ และบันทึกข้อมูลต้นทางไว้ใน docs เท่านั้น ไม่สร้างหน้าเครดิตสำหรับลูกค้า
